# Dashboard BI Thamrin

Dashboard proyek Renovasi Interior Lobby MSP, Optimalisasi GBI, dan Optimalisasi Taman Milenial.

## Modul utama

- Engineering Readiness
- Material & Long Lead
- BIM Coordination

## Menjalankan lokal

```bash
npm install
npm run build
```

Hasil build tersedia di folder `dist`.

## Deploy ke Vercel

Import repository ini ke Vercel. Konfigurasi build sudah tersedia pada `vercel.json`.
